# 查证器插件 (astrbot_plugin_lie_detector)

分析消息可信度的查证插件，支持 LLM 和规则双引擎，带 WebUI 管理面板。

---

## 安装

1. 将 `astrbot_plugin_lie_detector` 文件夹放入 AstrBot 的插件目录（`data/plugins/`）
2. 重启或重载 AstrBot
3. 在 WebUI 的插件页面找到「查证器」，点击进入即可看到配置项和管理面板

---

## 指令用法

**注意：** 所有指令都支持 `/查证` 和 `/测谎` 两个别名，效果完全相同。

### 1. 查证（基本功能）

**怎么用：** 先引用（回复）一条消息，然后发送 `/查证`

```
> 引用某人的消息
> /查证
```

插件会分析被引用消息的可信度，给出 0-100 的整数百分比评分和等级，并记录到被引用消息的作者（而非操作者）的统计数据中。

### 2. 查看全服排行榜

```
/查证 统计
```

显示所有有查证记录的用户排行榜，按平均分从高到低排列。

### 3. 查看某用户统计

```
/查证 统计 @某人
```

显示指定用户的平均可信度、等级和查证次数。

### 4. 重置用户数据（管理员）

```
/查证 重置 @某人
```

清除指定用户的所有查证记录和统计数据。只有管理员可以使用。

### 5. 查看帮助

```
/查证 帮助
```

显示所有可用指令的简要说明。

## WebUI 管理面板

在 AstrBot WebUI 的插件页面，点击查证器插件卡片进入详情页，可以看到「管理面板」页面。

**面板功能：**

- **总览统计：** 显示用户总数、查证总数、全服平均分
- **玩家列表：** 按平均分排序显示所有用户（显示完整QQ号），点击任意用户进入详情
- **玩家详情：** 显示该用户的平均分、等级、查证次数，以及每一次查证的完整记录（时间、评分、等级、理由、消息预览）
- **修改评分：** 点击记录旁的「修改」按钮，可以直接修改某条记录的评分
- **删除记录：** 点击记录旁的「删除」按钮，可以删除单条查证记录
- **重置用户：** 在玩家详情页点击「重置该用户」按钮，清除该用户所有数据

## 配置说明

在 WebUI 插件详情页可以直接配置以下所有选项，无需手动编辑文件。

### LLM 设置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 启用LLM分析 | 开启后使用大模型分析消息可信度，关闭则使用内置规则引擎 | true |
| LLM模型提供商 | 选择要使用的模型提供商，留空则使用当前会话默认的提供商 | （空） |
| LLM提示词模板 | LLM 分析时使用的提示词，`{message}` 会被替换为被查证的消息内容 | （内置默认模板） |

### 规则引擎设置

当 LLM 不可用或被关闭时，使用规则引擎分析。

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 规则引擎-基础分 | 分析时的起始分数 | 50 |
| 规则引擎-细节加分 | 每个细节特征（数字、时间、地点）的加分值 | 6 |
| 规则引擎-最佳长度下限 | 消息长度在此范围内加分 | 10 |
| 规则引擎-最佳长度上限 | 消息长度在此范围内加分 | 80 |
| 规则引擎-长度适中加分 | 长度在最佳区间时的加分值 | 15 |
| 规则引擎-夸张词扣分 | 每个反常识/夸张词的扣分值 | 20 |
| 规则引擎-绝对词扣分 | 每个绝对化表述的扣分值 | 10 |
| 规则引擎-模糊词扣分 | 每个模糊表述的扣分值 | 10 |
| 规则引擎-情感符号加分 | 消息含情感符号时的加分值 | 5 |

### 功能开关

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 显示历史平均分 | 在查证结果中显示被查证用户的历史平均可信度 | true |
| 排行榜显示人数 | 排行榜最多显示的用户数量 | 20 |
| 仅管理员可用 | 开启后普通用户无法使用查证指令，管理员不受限制 | false |
| 每日查证次数限制 | 每位用户每天可查证次数，0 表示不限制 | 0 |
| 消息最小长度 | 被查证消息少于该长度则提示过短 | 2 |

### 数据库设置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 存储历史记录 | 是否存储详细查证历史记录到数据库 | true |
| 历史记录保留天数 | 超过该天数的历史记录将被自动清理，0 为永久保留 | 30 |

### 显示设置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 显示分析理由 | 在查证结果中显示详细分析理由 | true |
| 显示等级图标 | 在结果中显示等级图标 | true |

### 等级阈值（分数 ≥ 该值时判定为该等级）

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 阈值-可信 | 分数 ≥ 该值为「可信」 | 80 |
| 阈值-基本可信 | 分数 ≥ 该值为「基本可信」 | 60 |
| 阈值-存疑 | 分数 ≥ 该值为「存疑」 | 40 |
| 阈值-可疑 | 分数 ≥ 该值为「可疑」 | 20 |
| 阈值-虚假 | 分数 ≥ 该值为「虚假」 | 0 |

### 等级名称

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 等级名称-可信 | 可信等级的显示名称 | 可信 |
| 等级名称-基本可信 | 基本可信等级的显示名称 | 基本可信 |
| 等级名称-存疑 | 存疑等级的显示名称 | 存疑 |
| 等级名称-可疑 | 可疑等级的显示名称 | 可疑 |
| 等级名称-虚假 | 虚假等级的显示名称 | 虚假 |

## 文件结构

```
astrbot_plugin_lie_detector/
├── __init__.py              # Python 包标识
├── main.py                  # 插件主代码
├── _conf_schema.json        # 插件配置定义（WebUI 自动读取）
├── metadata.yaml            # 插件元数据
├── requirements.txt         # 依赖声明
├── pages/
│   └── dashboard/
│       ├── index.html       # WebUI 管理面板页面
│       ├── app.js           # 前端逻辑
│       └── style.css        # 样式
└── data/                    # 数据目录（自动创建，位于 AstrBot 根目录）
    └── lie_detector.db      # SQLite 数据库
```

**注意：** 数据存储于 AstrBot 根目录的 `data/astrbot_plugin_lie_detector/` 目录下，而非插件自身目录，防止插件更新时数据丢失。
